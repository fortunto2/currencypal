# CLAUDE.md — CurrencyPal

## Overview

**CurrencyPal** (App Store name: **CurrencyPals**) is a privacy-first, offline-first currency
converter for iOS. No accounts, no tracking, no cloud. Rates are cached on-device via SwiftData and
conversion runs locally. Every row in the list is editable — type in any currency and the rest
recalculate.

**Problem:** Travellers waste time on daily "math tax" while existing converters bombard with ads,
require accounts, and break offline.

**Stack:** iOS 17+ / Swift 6 (strict concurrency) / SwiftUI / SwiftData / Swift Charts

## Domain Models (Read These First)

- `Models/Currency.swift` — `CurrencyCode` (31 fiat + 5 crypto), `ExchangeRate` (USD-based cache),
  `SelectedCurrency` (user's list + order), `HistoricalRate` (chart cache)
- `Models/FrankfurterResponse.swift` — API response shapes

## Architecture

- **MVVM** — `@Observable @MainActor` view models; views hold no logic
- **USD pivot** — every rate is cached as "1 USD = X target". Cross rates are computed as
  `(USD→Y) / (USD→X)`, so switching the active row needs no network call
- **Rates live in memory** — `ConverterViewModel.usdRates`. Conversion never touches SwiftData;
  typing used to run two fetches per currency per keystroke and visibly lagged
- **Networking is separate from persistence** — `ExchangeRateService` only returns a `RateSnapshot`.
  The cache is replaced only after a fetch succeeds
- **Offline-first** — a failed refresh keeps the previous rates and reports it; it must never clear
  the cache first

## APIs

| Provider | Used for | Notes |
|---|---|---|
| `api.frankfurter.dev` | ECB fiat rates, fiat time series | Free, no key. **No RUB.** |
| `api.coingecko.com` | Crypto prices + history | Free, no key, aggressively throttled |
| `open.er-api.com` | Currencies the ECB omits (RUB) | Free, no key. No history. |

**CoinGecko gotchas (both hit in production, both handled — don't reintroduce):**
- Returns **429 after roughly three calls** from one IP. Charts therefore serve a cache younger than
  12 h without any request, and a throttled call gets one backoff retry.
- **Do not pass `interval=daily`** — on the keyless tier it answers with a window months out of
  date. Request default granularity and collapse the hourly series with `collapseToDaily`.

## Key Decisions

- No CloudKit/Firebase/accounts — local only
- Frankfurter over paid APIs — free, institutional (ECB), enough for daily rates
- Amounts use the **locale's** decimal separator, with no grouping separator, so a displayed value
  can be typed back into the field
- Focusing a row **clears it** and shows the old value as the placeholder. Emulating select-all
  fails: a tap on a right-aligned number puts the caret wherever it landed, so typing "100" over
  "0.88" produced "1000.88"
- `-uiTesting` launch argument swaps in an in-memory store so UI tests are isolated

## Don't

- Don't add cloud sync or accounts
- Don't use UIKit (SwiftUI only)
- Don't make network calls for anything other than exchange rates
- Don't collect or store any user personal data — the App Store listing declares "data not collected"
- Don't clear the rate cache before a successful fetch
- Don't do SwiftData queries in the typing path
- Don't edit `CurrencyPal.xcodeproj` by hand

## Do

- Do read `Models/` first
- Do keep all conversion math on-device
- Do show rate freshness (green fresh, orange after 4 h)
- Do use Swift Testing (`@Test`) for logic and XCUITest for interaction
- Do regenerate `store/screenshots/` via `ScreenshotTests` after UI changes
